## Method summary

- **Data:** NSL-KDD, KDDTrain+ for training, full KDDTest+ for testing.
- **Preprocessing (fit on train only):** one-hot of 3 categorical columns (122 columns) → top-30 by mutual information → MinMax scaling.
- **Imbalance:** SMOTE applied to training folds only.
- **Model:** Random Forest (500 trees, depth 15) + XGBoost (300 estimators, lr 0.05, depth 6); logistic-regression meta-learner trained on out-of-fold probabilities.
- **Metrics:** reported both as binary (attack vs normal) and as 5-class weighted averages; mean ± std over 3 seeds.
- **Adversarial:** HopSkipJump and ZOO through ART's `BlackBoxClassifier`, seeded random test sample, results on raw and on projected-to-valid adversarial points, 95% Wilson intervals.
- **Latency:** model inference only (batch of 512), not end-to-end.
